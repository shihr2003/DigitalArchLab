Orthomosaic in QGIS

Project Setup in QGIS

This page will guide you to analyze archaeological features in Echo Mesa using the orthomosaic you have just generated. Start QGIS and open a new project. Save it () in your Digital Archaeology Lab folder with a filename such as lab2_EchoMesa_Hopi_Your_LastName.qgz.

Change the CRS to EPSG:32612 to match that of the orthomosaic.

As before, from the Browser panel, drag a basemap such as Bing maps from XYZ Tiles to your Layers.

If any of the panels are not there, select View -> Panels to toggle them on.

Adding Data

Orthomosaic and DEM

In QGIS, add both the DEM and orthomosaic .tif files as raster layer. In the Layers panel, toggle off DEM and compare the resolution between the orthomosaic and the basemap.

Thermal Imagery

Finally, add echocanyon_thermal_8may25_utm.tif as a raster layer. You may notice that the image looks rather “muted.”

To troubleshoot, we may need to examine the distribution of the pixel values. Right click on the thermal layer and select Properties. In Layer Properties window, go to Histogram and click Computer Histogram.

Note

For a single-band image such as this thermal image, a GIS program typically maps the range of pixel values onto a grayscale (0-255), from black for the lowest value to white for the highest.

As you can see here, the raster displays poorly because a few outlying values stretch this range. Most pixels fall within only about 10% of it, so they are squeezed into a narrow band of grays, and the variation within the histogram’s main peak is hard to see.

To change this, go to Symbology dialog in Layer Properties. In the Min/Max Value Settings, select Cumulative count cut and choose 10 - 90%.

You should now have a much better visualization of the thermal data.

Archaeology of Echo Mesa

A typical archaeological site in Echo Canyon consists of stone building foundations and artifact scatter at the surface:

In QGIS map view, one similar site can be found near coordinates 570324.3092,3972901.0257. Locate this point and set the scale to 1:30.

Toggle off all layers except for the orthomosaic. Can you see the archaeological feature here?

To map this feature, we will need to create a new vector layer. Go to Layer -> Create Layer -> New GeoPackage Layer.... In the pop-up window, first click ... next to the File name and select a location to save your layer with a reasonable name.

For Geometry type, select Polygon, and select Project CRS. In New Field, write ID in the Name field and change Type to Integer. Press Add to Fields List. Finally, press OK.

In the Layers panel, right-click on the newly created layer and select Toggle Editing (). This will let you edit the .gpkg file directly. In the top toolbars, select Add Polygon Feature () and start tracing the boundary of the archaeological site. Once done, hold Ctrl and click anywhere on the map. In the pop-up window, put 0 in the ID field, indicating this is the first site you map.

There you go — you have just mapped your first archaeological feature in QGIS! It should look something like this:

Once you are done, select Save Layer Edits () in the top toolbar. Click Toggle Editing () again to exit edit mode.
